# SMOKEY VOX releases

Signed macOS builds of the SMOKEY VOX plug-in, formerly Septet (VST3 and Audio Unit, universal).

Current: **SMOKEY VOX 1.7.1 (build 54)** in `septet-b54/`.

Installed copies, including ones still called Septet, update from here by themselves and check the signature before installing. There is nothing to download by hand.
